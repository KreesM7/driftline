# Roadmap

## Validate preview

- Native macOS/Linux and permission-failure checks in disposable VMs/devices.
- Study 10–15 users: time to useful action, misunderstood results, repeat use, harmful advice.
- Labeled parser benchmark with false positives/negatives against explicit ground truth.
- Fluent Arabic evidence/guidance review.
- Install/uninstall, Docker, remote CI, CodeQL, release contents, and signing verification.

## Next

Improve reliable offline update evidence; add supported Linux desktop lock checks; document intentionally enabled remote access; add state locking before any scheduled checks.

Broader controls and signed community packs require demand and threat review. Network scanning, credentials, automated hardening, and cloud collection remain outside current direction.
